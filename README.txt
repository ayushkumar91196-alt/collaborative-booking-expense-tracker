# Collaborative Booking & Expense Tracker App 📱

A feature-rich Android application built in Java for users to seamlessly manage bookings and track daily expenses dynamically with local persistence.

## Tech Stack
* **Language:** Java
* **Platform:** Android Studio
* **Database:** SQLite & SharedPreferences
* **Project Management:** Jira (Agile Sprint Tracking)

## Features
* **Dynamic Booking Management:** Add, update, and manage bookings in real-time.
* **Expense Tracker:** Log daily expenses with categorization and local storage persistence.
* **Notifications:** Integrated notification manager for reminders and alerts.
* **Custom UI Layouts:** Designed responsive user interfaces using ConstraintLayout and Material Design components.
